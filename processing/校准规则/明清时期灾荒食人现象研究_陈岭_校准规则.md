## 清洗条件

### 1. 省级标题格式
**规则**：省/自治区/直辖市名称后跟冒号（如 `河南：`、`山东：`），**不能**加 `#` 符号。

**正确格式**：
```
河南：
```

**错误格式**：
```
# 河南：
```

### 2. 单条目跨行问题
**规则**：一个完整的地区条目（包含地区名 + 灾情描述 + 引用来源）应在一行内，不能被意外拆分成多行。

**正确格式**：
```
黎城县：自春徂夏，不雨。岁大饥，人相食，时斗米银五钱，虽父子兄弟夫妇互相杀食，僻径荒郊无敢独行者。——康熙《黎城县志》卷二纪事
```

**错误格式**（条目被意外换行）：
```
黎城县：自春徂夏，不雨。岁大饥，人相食，时斗米银五钱，虽父子兄弟夫妇互相杀食，僻径荒郊无敢独行者。——康熙《黎城县志》
卷二纪事
```

### 3. 多条目合并问题
**规则**：不同地区的条目应在各自独立的行中，不能合并在同一行。

**正确格式**：
```
沁水县：岁大祲，米价数倍平时。民多饿死，人相食。——康熙《沁水县志》卷九祥异

翼城县：大旱，岁游饥。人相食，大疫。——乾隆《翼城县志》卷二十六祥异
```

**错误格式**（两地合并为一行）：
```
沁水县：...。——康熙《沁水县志》卷九祥异翼城县：大旱，岁游饥。人相食，大疫。——乾隆《翼城县志》卷二十六祥异
```

### 4. 引用来源拆分问题
**规则**：引用来源（如书名、卷号、出处）应与条目主体在同一行，不能拆分。

**正确格式**：
```
陇西县：秋大旱，饥。十月，栗价腾贵，斗米三百钱。次年春，价至十倍，绝籴罢市。木皮石面皆食尽，父子夫妇相割啖，十死八九，道瘞相望。——乾隆《陇西县志》卷十二祥异
```

**错误格式**（引用被拆分）：
```
陇西县：秋大旱，饥。十月，栗价腾贵，斗米三百钱。次年春，价至十倍，绝籴罢市。

木皮石面皆食尽，父子夫妇相割啖，十死八九，道瘞相望。——乾隆《陇西县志》卷十二祥异
```

### 5. 年号标题与条目合并问题
**规则**：年号标题（如 `### 明世宗嘉靖四十四年（1565年）`）应独立成行，后面才是具体条目。

**正确格式**：
```
### 明世宗嘉靖四十四年（1565年）

山西：

太谷县：...
```

**错误格式**（年号与条目合并）：
```
### 山西：太谷县：...灾异明世宗嘉靖四十四年（1565年）
```

### 6. 省份与地区条目合并问题
**规则**：省级标题（如 `辽宁：`、`山东：`）与下属地区条目（如 `辽阳市：`、`淄博市：`）不应在同一行，省级标题应独立成行，地区条目另起一行。

**正确格式**：
```
辽宁：

辽阳市：（明）御史周斯盛《发帑救荒疏》：臣照得辽东地方...——康熙《盛京通志》卷三十二
```

**错误格式**（省份与地区合并）：
```
辽宁：辽阳市：（明）御史周斯盛《发帑救荒疏》：臣照得辽东地方...——康熙《盛京通志》卷三十二
```

```
山东：淄博市：春饥，人相食。四月，雹，大有如斗者。——万历《淄博县志》卷二十二灾祥
```

### 7. 保留的合法换行
**说明**：以下情况换行是**合法且正确的**，不应修改：

1. **省份级别的大段描述**：某些省份（如"山东："）后面跟着全省性的综述文字，这些描述可能本身就分段，这是正确的格式。

2. **月份/日期的正常换行**：如"十月丁丑"等日期独立成行是正常的史书格式。

3. **年号章节标题**：`###` 开头的大明/大清年号标题应独立成行。
