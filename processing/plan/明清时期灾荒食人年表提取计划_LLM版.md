# 计划：使用 LLM 提取食人资料（LLM 版）

## 目标
从 `data/校准版/明清时期灾荒食人现象研究_陈岭_校准版.md` 提取食人记录到 CSV。

## 提示词设计

### System Prompt
```
你是一个历史数据提取专家，负责从明清时期灾荒记录中提取食人相关事件。你的输出必须严格遵循给定的 JSON 格式。
```

### User Prompt

**提取标准**：
- 提取：`人相食`、`相食`、`民相食`、`父子相食`、`兄弟相食`、`至相食`、`多相食`、`人有相食者`、`易子而食`、`割人肉`、`杀人而食`、`食人肉`、`自食其子/父`
- **不提取**：仅描述饥荒但未提及食人行为的记录

**输出格式**：
```json
[{
  "province": "省",
  "city": "市（如无填'无'）",
  "county": "县（如无填'无'）",
  "ancient_name": "古代地名（如无填'无'）",
  "year_ce": 公元年份,
  "year_era": "年号",
  "source": "来源（仅书名）",
  "note": "备注（如无填'无'）"
}]
```

**边界条件处理**：
1. **来源处理**：去除年号/卷次，`康熙《续修陈州志》卷四灾异` → `《续修陈州志}`；转引保留原始来源
2. **古代地名**：`泽州`→`山西省晋城市`，`解州`→`山西省运城市`，`绛州`→`山西省运城市新绛县`，`秦州`→`甘肃省天水市`，`肃州`→`甘肃省酒泉市`，`代州`→`山西省忻州市代县`，`平阳府`→`山西省临汾市`；现代仍在用的地名（庆阳、庄浪、辽东）不记为古代地名
3. **OCR错误**：`个人信息` → 标注"疑似OCR错误"
4. **顿号多县**：`曲沃、洪洞、临汾` → 拆分为3条
5. **县等格式**：`静宁县等：静宁、灵台、肃州等处` → 拆分为3条
6. **泛指跳过**：`两京、山东、河南、湖广...`等多省泛指不提取；`淮、扬、庐、凤等府饥`等府级泛指不提取
7. **特殊地名**：`秦、晋`→陕西、山西（备注说明）；`都下`→北京

**输出要求**：
- 只输出 JSON 数组，不要其他文字
- year_ce 必须是数字
- 无食人记录的年份返回 `[]`

## 程序框架

```
输入文件 → 按年份分段 → 逐年调用 LLM → 解析/验证 JSON → 合并输出 CSV
```

### 核心函数

| 函数 | 功能 |
|------|------|
| `extract_year_segments()` | 按 `###` 标题分段，返回 `[(年号, 公元年, 内容)]` |
| `call_llm_extract()` | 调用 MiniMax API 提取 |
| `parse_llm_response()` | 解析 JSON，提取数组 |
| `validate_record()` | 验证字段，填充默认值 |
| `main()` | 流程编排 + CSV 输出 |

### 关键文件
- 输入：`data/校准版/明清时期灾荒食人现象研究_陈岭_校准版.md`
- 脚本：`processing/plan/extract_famine_data_llm.py`
- 输出：`result/明清时期灾荒食人年表.csv`
