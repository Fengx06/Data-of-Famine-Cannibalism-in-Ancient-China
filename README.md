# 明清时期灾荒食人现象研究

本项目研究明清时期（1368-1912年）中国灾荒期间的食人现象。

## 项目结构

```
├── data/
│   └── raw/                # 原始数据
├── processing/             # 数据处理脚本
│   ├── scripts/
│   └── notebooks/
├── output/                 # 处理结果输出
├── reference/              # 参考资料
│   └── 明清时期灾荒食人现象研究_陈岭.pdf
├── LICENSE
└── README.md
```

## 数据来源

原始数据来自陈岭的研究论文《明清时期灾荒食人现象研究》。
